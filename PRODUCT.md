# Mohammed El-Stohy portfolio

Separate, single-owner Next.js portfolio and private content dashboard. The previous project is read-only. Public mode: Experience. Dashboard mode: Operate. Porto is the pinned visual and motion authority, not an inspiration board. Real app screenshots and factual descriptions are sourced from the previous live site's published work pages; no employer names, personal geography, phone numbers or fabricated achievements. No old resume is copied or published. No public registration, billing, organizations or tenancy. Browser-local clock only. Firebase email/password authentication and admin documents authorize edits at the database and protected API boundaries. Images use signed direct Cloudinary uploads. Server-rendered public content excludes drafts. Cloudflare Workers is the deployment target.
